# Veterinary Fieldnotes private master archive

This repository starts empty. It is a separately protected destination for authorized permanent Markdown/JSON knowledge and non-sensitive processing status, not a source of public website assets.

No audio, temporary transcripts, API credentials, backup keys, or SQLite ledgers belong here. Private repository visibility alone does not authorize third-party clinical storage. The pipeline refuses clinical synchronization unless both explicit configuration and command authorization are supplied.

Use the application repository's `docs/OPERATIONS.md` for synchronization, encrypted independent backups, and recovery. Set collaborator access and retention according to actual authorization before adding clinical material.
