# Public privacy and study research

Public content is a separate copy. Recordings, transcripts, canonical extraction,
real names, identity evidence and model responses remain private. The automatic
publisher must have the owner's authorization and `patientNamePolicy` set to
`owner-species-sex-v1`; the policy setting does not grant publication consent.

| Established patient traits | Public name |
| --- | --- |
| Male dog | Spot |
| Female dog | Bella |
| Male cat | Pickles |
| Female cat | Donut |
| Dog, sex unknown | Dog X |
| Cat, sex unknown | Cat X |
| Species unknown or another species | Patient X |

These are shared aliases, never numbered. A real animal name already matching its
assigned alias may stay. Separate case IDs preserve separate cases. Names never
establish species or sex. Conflicting or explicitly unknown traits remain unknown.
People and clinics do not receive the animal-alias exception.

Before publication, local Qwen identifies names and spelling variants across the
candidate human-readable fields. Its private catalog binds literal source evidence,
input and policy. Per-record caches avoid rechecking unchanged material. Deterministic
replacement runs before the existing semantic privacy gate, and a final known-name
check inspects the result. Ordinary medical phrases sharing a name are preserved.
Ambiguous identity records stay private. This is automated privacy screening, not
a guarantee of clinical accuracy or a substitute for owner review.

With `question_verification.research_enabled=true`, the separate restricted study
researcher can search and read public PubMed/PMC literature through Europe PMC.
It is a local search/read workflow, not unrestricted web browsing. Only validated,
short generic medical concepts and species leave the machine; private source text,
questions, names and histories do not. Retrieved abstracts or available open-access
full text retain source URLs, hashes and retrieval dates outside source Git.

The medical checker evaluates the core teaching and allows reasonable synthesis
from relevant evidence. It still holds contradictions, unsupported claims, ambiguous
answers and unverified options. If a private draft overclaims, a separate public
study-card proposal may narrow or correct it using actual references. Existing wording is checked first; supported originals are retained. The private
draft and extraction remain unchanged. A proposal needs independent verification
of its exact content and ordinary privacy review before publication. The website
adds the verified reference links.

The importer, researcher and publisher cooperate through the publication guard and
existing shared GPU admission checks. They do not evict another application's model.
Research retries preserve successful checkpoints. A medical hold cannot block
eligible articles and cases. Timer enablement, deployment receipts and real-session
progress belong in the private installation handoff, never this source document.

Model citations use the supplied excerpt IDs. A bare document ID is resolved only
when its quotation occurs exactly in a supplied excerpt of that same document.
New proofs bind every passage actually supplied to the judge. Changes to selected
evidence invalidate the proof; unrelated new papers do not. Historical proofs
retain their original stricter corpus binding.
